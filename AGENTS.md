# MMail

Android-only email client built with Kotlin 2.4.21, Compose Multiplatform 1.13.0-alpha02, and Material 3 Expressive. Modules: `androidApp` and `sharedUI`. The latter uses Kotlin Multiplatform with Android as its only target to retain the UI structure and Compose Resources. Package: `it.maicol07.mmail`.

## Conventions

- Write documentation, code identifiers, comments, default UI strings, and sample data in English. Italian UI translations belong in `composeResources/values-it`; localized test expectations may use Italian. Preserve proper names and package names.
- Shared UI and logic live in `sharedUI/src/commonMain`; screens in `ui/views/mailbox`, reusable components in `ui/components`, and the theme in `ui/theme`.
- `data/Mailbox.kt` contains the model and immutable transformations; production starts empty. `MailProvider` is the UI boundary. The Android `OutlookProvider` uses MSAL for authentication and `GraphClient` for Microsoft Graph v1.0. Keep fixtures in test sources.
- Mail IDs are opaque, case-sensitive strings. Request Graph immutable IDs on every call. Apply UI mutations only after server success; never retry sending automatically. A send accepted by Graph is not proof of delivery.
- Graph GET requests retry transport failures at most twice with bounded backoff. Writes are not retried. The `MMail` log tag records operation states and failure types without account identifiers, message contents, or tokens.
- Keep UI strings in Compose Resources.
- Dependencies belong in `gradle/libs.versions.toml`. Keep Compose and Material3 versions aligned.
- Use MaterialKolor with `DynamicMaterialExpressiveTheme` and `MotionScheme.expressive()`. Use semantic color roles, Material controls, and touch targets of at least 48 dp. Controls with built-in motion respect system settings.
- Filters belong in `FilterSheet`, opened from the top bar. The theme follows the system; there is no theme selector in the bar.
- `SharedTransitionLayout` and `AnimatedContent` connect avatars, subjects, and attachment chips during compact navigation. In the two-pane layout, use the detail transition without sharing elements already visible in the list. Mark messages as read after opening completes to preserve the transition source with the Unread filter.
- Icons are generated by SymbolCraft. Add names to the `symbolCraft` block in `sharedUI/build.gradle.kts`; do not edit generated files.
- Outlook requires Internet access and a public-client Microsoft Entra registration for personal and work/school accounts, with delegated `Mail.ReadWrite` and `Mail.Send`. Set `outlook.clientId` and the certificate's Base64 SHA-1 `outlook.signatureHash` in ignored `local.properties`. Never embed a client secret. MSAL owns token storage and renewal; do not log tokens or mail bodies.

## Verification

Use Android Studio's bundled JDK. Android SDK 37.2, target 37, minimum 26. Local configuration belongs in `local.properties`, excluded from Git.

```powershell
.\gradlew.bat :sharedUI:testAndroidHostTest :androidApp:assembleDebug :androidApp:assembleDebugAndroidTest
```

Run UI tests on a device or emulator with `:androidApp:connectedDebugAndroidTest`.
The connected-test runner can uninstall the target app after completion, removing its local MSAL session. Use a dedicated test device/emulator when an existing sign-in must be preserved.

## Current limitations

- Startup/sign-in and manual refresh load the first 100 message summaries from each supported folder (Inbox, Sent Items, Archive, Deleted Items). Keep Graph pagination cursors in `MailboxState.nextPages`; fetch subsequent pages when the list reaches its end (or through its accessibility action). Refresh by pulling down on the list; show operation progress below the top bar without blocking navigation. Fetch full plain-text bodies before opening a message. Never make startup wait for the whole mailbox.
- Mailbox and drafts are held in memory; there is no offline database or server draft saving. Search and counters cover loaded messages and content; message lists initially contain previews. Custom/nested folders and background/delta synchronization are not implemented. Starred shows flags in loaded folders excluding trash, and load-more follows non-trash folder cursors.
- Attachment chips open the original message in Outlook. Native attachment download/upload and HTML rendering are not implemented.
- Model host tests live in `sharedUI/src/commonTest`, Graph transport/mapping tests in `sharedUI/src/androidHostTest`, and compact UI instrumented tests with an injected test provider in `androidApp/src/androidTest`, using Compose test rule v2. Real Entra sign-in, token renewal, Android rotation, screen reader support, and real-device behavior require dedicated verification.
